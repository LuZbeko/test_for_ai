"Create a REST API for managing todos with the following requirements:
  1. CRUD operations for todos (Create, Read, Update, Delete)
  2. Each todo should have: id, title, description, completed status, and created_at timestamp
  3. Add input validation for title (required, max 100 chars) and description (max 500 chars)
  4. Include error handling with appropriate HTTP status codes
  5. Add a filter endpoint to get todos by completion status
  6. Write at least 3 unit tests for the main functionality"
